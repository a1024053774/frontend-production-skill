# Nova 仪表盘去 AI 味：改动报告（新版 Skill）

子代理写这个文件时被宿主拦下，下面的正文是主会话从它的回复里原样存下来的。它读过的 Skill 文件：SKILL.md、references/look-and-copy.md、references/unslop-passes.md、references/look-examples.md、references/visual-family.md。

状态：INCOMPLETE。源码已经改完，但没有在浏览器或真机上看过渲染效果。

## 方向
读者是老板和财务，每天看本月回款和逾期。这两个数要一眼就能读到。
- **样子**：做成月结台账。米白纸色底，墨黑数字，用细线分栏，不用卡片和阴影。只用一条深绿，放在品牌名、回款金额和导出按钮上。逾期数字用砖红。
- **记忆点**：40px 的等宽数字回款额 `$48,210`。
- **主行动**：`Export CSV`。原来按钮写的是 "Get Started 🚀"，点了实际是跳到 `/export.csv`。现在移到标题右边。

## 改造前普查（读源码得出，没看渲染）
- **间距**：17、19、22、26、33、37、13、9、11、7、3、6 都不在刻度上。
- **圆角**：有 28、999、14、12 四种，同一个角色用的圆角也不统一。
- **字号和字重**：字号 11、12、22、38、44；字重 600、700、800，几乎全部加粗。
- **颜色**：大约 20 种紫、粉、靛、青、橙，有渐变、玻璃效果和光晕。能说出含义的只有 delta 用的绿色。

新的间距刻度是 4、8、12、16、24、32、48。族卡写在 `style.css` 顶部的注释和 `:root` 的 token 里。

## 八道减法
1. **间距**：全部归到刻度上。剩下几个不在刻度上的值：13px 是字号；220px 是原来的图表高度；侧栏宽度从 260 改成 240；720px 是断点。
2. **去底色**：去掉了径向渐变、backdrop-filter、所有彩色阴影、渐变标题字和 logo 后面的渐变方块。
3. **对齐**：侧栏各项的左内边距统一成 12px。两张指标卡改成两栏台账，中间用竖线分开。
4. **图标**：删掉了全部 emoji 图标。项目里没有图标库，所以没有换成别的图标。套餐前面换成小圆点。
5. **文案**：
   - `NovaAI PRO ✨` 改成 `Nova`，页面标题改成 `Nova · Overview`。
   - `Welcome back, Alex! 👋` 改成 `Collections and overdue`。
   - 全大写的分组标题改成首字母大写，没有信息量的 `NAVIGATION` 删掉了。
   - 搜索框占位符改成 `Search`，并加了 `aria-label`。
   - 去掉了感叹号和情绪 emoji。`New ✨` 改成中性的 `New`。
6. **数字和图表**：
   - 数值一个没改：$48,210、+12%、3、$124,860.40、+4.2%、12、18、64、210，柱高 40%、85%、60%。显示上唯一的变化是 `07` 改成了 `7`。
   - 数字统一用 `tabular-nums`。
   - 图表加了基线，柱子下面加了套餐名，名字取自原来的 `title`。
   - 没有加 Y 轴刻度，因为没有对应的数据。
7. **字重**：只留 400 和 600。次要信息改用浅灰色。
8. **颜色加回来**：深绿表示品牌和回款，砖红表示逾期，三种套餐色各用一个 token，侧栏圆点和图表柱子共用。计数胶囊的彩色背景都去掉了。

**保留的功能**：id（search、export、bars）、5 个导航链接和 2 个事件处理都没动。另外新加了这些：
- `type="search"`
- `aria-current`
- `:focus-visible` 焦点样式
- 窄于 720px 时改成单栏

## 缺口和待定项
- **涨跌基准不明**：`+12%`、`3 fewer`、`+4.2% this month` 不知道和什么比。我没有自己补"vs 上月"这类说法，需要你确认基准。确认之前涨跌都用中性灰。
- **`07` 改成了 `7`**：数值没变。如果"不改数据"包括字面写法，改回 `07` 即可。另外不知道 7 指的是发票张数还是客户数，所以没加单位。
- **套餐数含义不明**：18、64、210 不知道是什么数量，也没加单位。
- **图表没有刻度**：柱高只是相对值，和 `$124,860.40` 是什么关系也不清楚。需要每个套餐的金额才能补上刻度。
- **搜索范围未定义**：现在的处理只是写入 `data-q`，并不真的搜索。所以占位符只能写 `Search`。
- **界面语言**：保留了英文和美元，因为没有材料说明目标市场。如果读者看中文，文案要重新定。
- **深色模式**：原来的页面是深色的，现在改成了浅色，没有做深色版本。
- **没验证的部分**：实际渲染效果、实测对比度、手机和真机上的效果、键盘焦点顺序。
